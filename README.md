Открой `index.html` напрямую в браузере или подними локальный сервер (см. [Запуск](#запуск)).

## Стек

- **HTML5** — семантическая разметка, ARIA-атрибуты
- **CSS3** — custom properties, `clamp()`, Grid/Flex, multi-tier media queries
- **Vanilla JS** — без зависимостей, ES2017+, `IntersectionObserver`
- **Локальные шрифты** — Inter Tight / Inter / JetBrains Mono (variable woff2, cyrillic + latin)

Никаких внешних CDN, шрифтовых сервисов, фреймворков, сборщиков и npm-зависимостей. Сайт полностью самодостаточен: работает офлайн после первой загрузки, ничего не утекает в Google/другие трекеры.

## Структура проекта

```
motodrive/
├── index.html      # главная — посадочная
├── policy.html     # Политика конфиденциальности
├── offer.html      # Договор публичной оферты
├── consent.html    # Согласие на обработку ПДн
├── cert.html       # Сертификат соответствия (заглушка)
├── styles.css      # дизайн-токены + стили
├── fonts.css       # локальные @font-face (без Google Fonts)
├── fonts/          # woff2-файлы (Inter Tight, Inter, JetBrains Mono)
├── app.js          # интерактив
├── index.js        # entry pointer (npm scripts)
├── package.json    # npm scripts
└── README.md
```

Все публичные файлы лежат **в корне репозитория** — это требование GitHub Pages по умолчанию (он отдаёт `index.html` из корня ветки).

### Шрифты

Шрифты (Inter Tight, Inter, JetBrains Mono) загружаются **локально** из папки `fonts/` — никаких внешних CDN. Variable-шрифты покрывают веса 400–800 одним файлом. Подмножества cyrillic + latin — минимум для русского сайта (~165 KB суммарно).

## Запуск

Любой статический сервер. Самый быстрый вариант:

```bash
npm run dev
```

Скрипт поднимет `serve` на http://localhost:5173 (используется `npx`, без глобальной установки).

Альтернативы:

```bash
# Python 3
python -m http.server 5173

# Node
npx serve . -p 5173

# PHP
php -S localhost:5173
```

## Сборка / деплой

Сайт полностью статический — никаких шагов сборки не требуется.

### GitHub Pages (рекомендуемый)

1. Закоммить всё в `master` ветку
2. **Settings → Pages → Build and deployment → Source:** `Deploy from a branch`
3. **Branch:** `master`, **Folder:** `/ (root)`
4. URL: `https://<user>.github.io/motodrive/`

### Другие хостинги

| Хостинг | Что сделать |
|---|---|
| Netlify / Vercel | Drop корень репозитория в UI или укажи `Publish directory: .` |
| Cloudflare Pages | `Build command:` _(пусто)_, `Build output: .` |
| S3 / Nginx | Загрузи файлы, отдавай `index.html` как `index` |

## Адаптив

Multi-tier брейкпоинты (от меньшего к большему):

| Ширина | Что меняется |
|---|---|
| **≥1280px** | Полная десктопная раскладка, hero в 2 колонки, 3 модели в ряд |
| **1024–1279px** | Hero в 2 колонки с уменьшенным визуалом; шаги компактнее |
| **881–1023px** | Hero всё ещё 2 колонки; навигация → бургер; модели и отзывы в 3 колонках |
| **881px↓** | Всё в одну колонку; бургер-меню; параллакс отключён |
| **600px↓** | Hero: dial 300px, stats уменьшены, чипы плотнее |
| **480px↓** | Типографика сжата, формы в 1 колонку, footer в 1 колонку |
| **380px↓** | iPhone SE: один чип скрыт, кнопки во всю ширину, hero-dial 240px |

### Мобильное меню

- Бургер появляется при ширине ≤880px
- Заменяет desktop-навигацию и CTA-кнопку в шапке
- Drawer раскрывается сверху, блокирует скролл body
- Закрывается: кликом на ссылку, ESC, ресайзом в desktop, повторным кликом по бургеру
- ARIA: `aria-expanded`, `aria-controls`, `aria-label`

### iOS-специфика

- `viewport-fit=cover` + `env(safe-area-inset-*)` для notch/dynamic island
- Шрифты в форме ≥16px (предотвращает авто-зум при фокусе на input)
- `-webkit-overflow-scrolling: touch` для плавного скролла
- `-webkit-tap-highlight-color: transparent` убирает серую подсветку
- Поля ввода: `inputmode="tel"`, `autocomplete="tel"`, `enterkeyhint="send"`
- 100dvh в mobile-nav для корректной высоты на iOS

## Дизайн-система

Токены в `:root` (`styles.css:4`):

| Переменная | Значение | Назначение |
|---|---|---|
| `--ink` | `#0E1116` | базовый тёмный фон |
| `--paper` | `#F5F2EB` | тёплый off-white для светлых секций |
| `--bolt` | `#FF6B1A` | моторный оранжевый — основной CTA |
| `--current` | `#4FB6E2` | электрик-голубой — вторичный акцент |
| `--mute` / `--mute-d` | серые оттенки | вторичный текст |
| `--font-d` | Inter Tight 800 | дисплейный (заголовки, цифры) |
| `--font-b` | Inter | body |
| `--font-m` | JetBrains Mono | технические данные, eyebrow |

Принцип: **главный акцент — `--bolt`**, остальное — дисциплинированная типографика и spacing.

## Секции

1. **Hero** — заголовок в 3 строки, lede, 2 CTA, 3 stat-числа, интерактивный спидометр (count-up + SVG-progress), плавающие чипы, бегущая строка-тикер
2. **Модели** — 3 карточки: City S1 / Trail S2 (featured) / Offroad X3
3. **Характеристики** — таблица из 6 строк с горизонтальными барами (анимация роста)
4. **Установка** — 3 этапа с обведёнными штрихом цифрами 01/02/03
5. **Отзывы** — 3 цитаты пользователей
6. **FAQ** — `<details>`-аккордеон с автозакрытием остальных
7. **Заказ** — форма: имя, телефон, выбор модели (с валидацией и success-состоянием)
8. **Footer** — 4 колонки: бренд, контакты, навигация, документы

## Кастомизация

**Изменить цвета:** отредактируй токены в `:root` (`styles.css:4`).

**Изменить контент:** все тексты — в `index.html`. Структура пронумерована `№01`…`№07` для удобства.

**Добавить секцию:** скопируй любой `<section class="section ...">` блок, поменяй `id`, добавь ссылку в `.nav__links` и `.mobile-nav__list`.

**Заменить placeholder-данные на реальные:**
- Телефон `+7 800 111-22-33` → ваш
- Email `hi@motodrive.ru` → ваш
- Адрес в footer → ваш
- Цены и характеристики моделей — в `<article class="model__item">`

## Производительность и доступность

- **Шрифты** с `display=swap` + локальный хостинг — текст виден сразу с fallback, ничего не уходит в Google
- **Шрифты-fallback** style-matched: serif-дисплей → Helvetica Neue → system-ui
- **Анимации** в `@media (prefers-reduced-motion: reduce)` отключены
- **Контраст**: body text ≥ 4.5:1 на обоих фонах (проверено)
- **Touch targets**: кнопки навигации, бургер, FAQ-summary ≥ 44×44 px
- **Фокус**: `:focus-visible` с оранжевым outline 2px
- **ARIA**: nav, mobile-nav, кнопки, аккордеон — все помечены
- **Семантика**: `<main>`, `<header>`, `<footer>`, `<nav>`, `<article>`, `<figure>`/`<figcaption>`
- **Prefers-color-scheme**: `meta color-scheme="dark light"` (боди всегда paper-bg, тёмные секции — by design)
- **Overflow-wrap** на текстовых блоках — длинные слова не ломают layout

## Юридические элементы

Все обязательные по законодательству РФ элементы размещены на сайте и в отдельных документах:

- **Маркировка рекламы** — блок под hero (`Реклама`, рекламодатель, erid — 38-ФЗ ст.5 п.1)
- **Идентификация рекламодателя** — ИП, ИНН, ОГРНИП в футере (38-ФЗ ст.5 п.1, ст.8)
- **Согласие на обработку ПДн** — отдельный чекбокс в форме заказа, не объединён с офертой и рекламной рассылкой (152-ФЗ ст.9, ред. 156-ФЗ от 24.06.2025, действует с 01.09.2025)
- **Акцепт оферты** — отдельный чекбокс в форме заказа (не смешан с согласием на ПДн)
- **Реквизиты оператора** — наименование и место нахождения в политике и в футере (152-ФЗ ст.14 ч.7, ст.18.1)
- **Уведомление Роскомнадзора** — порядок описан в политике (152-ФЗ ст.22)
- **Политика обработки ПДн** — `policy.html`
- **Договор публичной оферты** — `offer.html`
- **Согласие на обработку ПДн (полный текст)** — `consent.html`
- **Сертификат соответствия** — `cert.html` (заглушка до получения реального сертификата)

### Что специально НЕ сделано (и почему)

- **Никаких рекламных трекеров и пикселей** — VK Pixel, Facebook Pixel, Яндекс.Метрика не подключены. Cookie, IP и идентификаторы устройств по практике судов относятся к ПДн (ст. 3 152-ФЗ, «косвенно определяемое лицо»), а обязательство получать согласие под ретаргетинг выводится из ст. 6 и ст. 9 152-ФЗ. Пока трафик органический и трекеров нет, чек-бокс под рекламу не нужен.
- **Никаких иконок Meta/Facebook/Instagram в футере** — демонстрация символики запрещённых организаций ч. 1 ст. 20.3 КоАП.
- **Никакой рекламы на заблокированных площадках (72-ФЗ)** — рекламные каналы должны быть российскими (ВКонтакте Реклама, Яндекс Директ, Telegram Ads).
- **Согласие на рекламную рассылку (38-ФЗ ст.18)** — отдельным чекбоксом не сделано, так как на момент запуска рассылки не ведутся. При подключении email/SMS-рассылки добавить третий отдельный чекбокс.

### Placeholder-маркеры (`*`)

Все данные, которые являются заполнителями и **обязательны к замене до публичного запуска**, помечены звёздочкой `*` и сноской внизу страницы:

- Реквизиты ИП (ИНН, ОГРНИП, юридический адрес)
- Телефон, email (если не реальные)
- Цены и технические характеристики моделей
- «Хит продаж» (недостоверная реклама — 38-ФЗ ст.5 п.3)
- «Сделано в России» (не подтверждено)
- Имена в отзывах
- erid-токен (присваивается ОРД после запуска рекламной кампании)

> ⚠️ **Не запускай сайт в продакшн до замены всех placeholder-маркеров на актуальные данные.**
> Дополнительно рекомендуется юридическая проверка соответствия категории ТСР (технические средства реабилитации) требованиям Росздравнадзора, а также — подача уведомления в Роскомнадзор по ст. 22 152-ФЗ до начала обработки заявок с использованием средств автоматизации.

- Тёмная/светлая тема через `prefers-color-scheme` + тумблер
