## Demo

Открой `src/index.html` напрямую в браузере или подними локальный сервер (см. [Запуск](#запуск)).

## Стек

- **HTML5** — семантическая разметка, ARIA-атрибуты
- **CSS3** — custom properties, `clamp()`, Grid/Flex, multi-tier media queries
- **Vanilla JS** — без зависимостей, ES2017+, `IntersectionObserver`
- **Google Fonts** — Inter Tight, Inter, JetBrains Mono (с fallback на системные шрифты)

Никаких фреймворков, сборщиков и npm-зависимостей. Весь сайт — три файла в `src/`.

## Запуск

Любой статический сервер. Самый быстрый вариант:

```bash
npm run dev
```

Скрипт поднимет `serve` на http://localhost:5173 (используется `npx`, без глобальной установки).

Альтернативы:

```bash
# Python 3
python -m http.server 5173 -d src

# Node
npx serve src -p 5173

# PHP
php -S localhost:5173 -t src
```

## Сборка / деплой

Сайт полностью статический — просто загрузи содержимое `src/` на любой хостинг:

| Хостинг | Что сделать |
|---|---|
| GitHub Pages | `Settings → Pages → Source: /src` (или перенеси файлы в корень) |
| Netlify / Vercel | Drop `src/` в UI или укажи `Publish directory: src` |
| Cloudflare Pages | `Build command:` _(пусто)_, `Build output: src` |
| S3 / Nginx | Загрузи файлы, отдавай `index.html` как `index` |

## Адаптив

Multi-tier брейкпоинты (от меньшего к большему):

| Ширина | Что меняется |
|---|---|
| **≥1280px** | Полная десктопная раскладка, hero в 2 колонки, 3 модели в ряд |
| **1024–1279px** | Hero в 2 колонки с уменьшенным визуалом; шаги компактнее |
| **881–1023px** | Hero всё ещё 2 колонки; навигация → бургер; модели и отзывы в 3 колонках |
| **881px↓** | Всё в одну колонку; бургер-меню; параллакс отключён |
| **600px↓** | Hero: dial 300px, stats уменьшены, чипы плотнее |
| **480px↓** | Типографика сжата, формы в 1 колонку, footer в 1 колонку |
| **380px↓** | iPhone SE: один чип скрыт, кнопки во всю ширину, hero-dial 240px |

### Мобильное меню

- Бургер появляется при ширине ≤880px
- Заменяет desktop-навигацию и CTA-кнопку в шапке
- Drawer раскрывается сверху, блокирует скролл body
- Закрывается: кликом на ссылку, ESC, ресайзом в desktop, повторным кликом по бургеру
- ARIA: `aria-expanded`, `aria-controls`, `aria-label`

### iOS-специфика

- `viewport-fit=cover` + `env(safe-area-inset-*)` для notch/dynamic island
- Шрифты в форме ≥16px (предотвращает авто-зум при фокусе на input)
- `-webkit-overflow-scrolling: touch` для плавного скролла
- `-webkit-tap-highlight-color: transparent` убирает серую подсветку
- Поля ввода: `inputmode="tel"`, `autocomplete="tel"`, `enterkeyhint="send"`
- 100dvh в mobile-nav для корректной высоты на iOS

## Дизайн-система

Токены в `:root` (`src/styles.css:4`):

| Переменная | Значение | Назначение |
|---|---|---|
| `--ink` | `#0E1116` | базовый тёмный фон |
| `--paper` | `#F5F2EB` | тёплый off-white для светлых секций |
| `--bolt` | `#FF6B1A` | моторный оранжевый — основной CTA |
| `--current` | `#4FB6E2` | электрик-голубой — вторичный акцент |
| `--mute` / `--mute-d` | серые оттенки | вторичный текст |
| `--font-d` | Inter Tight 800 | дисплейный (заголовки, цифры) |
| `--font-b` | Inter | body |
| `--font-m` | JetBrains Mono | технические данные, eyebrow |

Принцип: **главный акцент — `--bolt`**, остальное — дисциплинированная типографика и spacing.

## Секции

1. **Hero** — заголовок в 3 строки, lede, 2 CTA, 3 stat-числа, интерактивный спидометр (count-up + SVG-progress), плавающие чипы, бегущая строка-тикер
2. **Модели** — 3 карточки: City S1 / Trail S2 (featured) / Offroad X3
3. **Характеристики** — таблица из 6 строк с горизонтальными барами (анимация роста)
4. **Установка** — 3 этапа с обведёнными штрихом цифрами 01/02/03
5. **Отзывы** — 3 цитаты пользователей
6. **FAQ** — `<details>`-аккордеон с автозакрытием остальных
7. **Заказ** — форма: имя, телефон, выбор модели (с валидацией и success-состоянием)
8. **Footer** — 4 колонки: бренд, контакты, навигация, документы

## Кастомизация

**Изменить цвета:** отредактируй токены в `:root` (`src/styles.css:4`).

**Изменить контент:** все тексты — в `src/index.html`. Структура пронумерована `№01`…`№07` для удобства.

**Добавить секцию:** скопируй любой `<section class="section ...">` блок, поменяй `id`, добавь ссылку в `.nav__links` и `.mobile-nav__list`.

**Заменить placeholder-данные на реальные:**
- Телефон `+7 800 111-22-33` → ваш
- Email `hi@motodrive.ru` → ваш
- Адрес в footer → ваш
- Цены и характеристики моделей — в `<article class="model__item">`

## Производительность и доступность

- **Шрифты** с `display=swap` + `preconnect` — текст виден сразу с fallback
- **Шрифты-fallback** style-matched: serif-дисплей → Helvetica Neue → system-ui
- **Анимации** в `@media (prefers-reduced-motion: reduce)` отключены
- **Контраст**: body text ≥ 4.5:1 на обоих фонах (проверено)
- **Touch targets**: кнопки навигации, бургер, FAQ-summary ≥ 44×44 px
- **Фокус**: `:focus-visible` с оранжевым outline 2px
- **ARIA**: nav, mobile-nav, кнопки, аккордеон — все помечены
- **Семантика**: `<main>`, `<header>`, `<footer>`, `<nav>`, `<article>`, `<figure>`/`<figcaption>`
- **Prefers-color-scheme**: `meta color-scheme="dark light"` (боди всегда paper-bg, тёмные секции — by design)
- **Overflow-wrap** на текстовых блоках — длинные слова не ломают layout

## Что можно улучшить

Идеи для следующих итераций (не реализовано в текущей версии):

- Подключить реальный backend для формы заказа (POST на API)
- Заменить placeholder-фото на реальные снимки мотоприводов (CSS-градиенты сейчас работают как «design honest» заглушки)
- Добавить видео-демонстрацию установки в секцию «Как установить»
- Локализация (i18n) на английский
- Тёмная/светлая тема через `prefers-color-scheme` + тумблер
- A/B-тест двух вариантов hero-заголовка
