# Wheel Pilots — заметки для агента

Одностраничный лендинг `Wheel Pilots Power` (электроприставка к инвалидной коляске).
Vanilla HTML/CSS/JS, без сборщика. Дев-сервер: `npx serve . -p 5173` или `npm run dev`.

## Правила работы с локальным сервером

- **Не поднимай локальный dev-сервер, если пользователь бездействует 3 часа подряд** — не запускай `npx serve .` и не поднимай его в фоне без явного запроса.
- Если сервер уже работает и упал по таймауту — **не перезапускай автоматически**, дождись следующего сообщения пользователя.
- Часовой лимит фоновых bash-задач делает рестарт каждый час раздражающим циклом. Лучше: пользователь явно попросил поднять → поднял один раз → держится пока не попросят остановить.

## Когда всё-таки нужен сервер

- Если пользователь просит «открой / покажи / проверь как выглядит» — это явный сигнал поднять сервер.
- Для верификации CSS/HTML-изменений — поднять, проверить `200 OK` на ключевых путях, доложить.

## Стек

- `index.html` — основная страница (≈1700 строк, секции пронумерованы `№01`…`№07`)
- `styles.css` — стили, токены в `:root`, mobile-first брейкпоинты 1100/880/600/420
- `app.js` — vanilla JS, без зависимостей; FAQ-обработчик, форма, sticky-tabs, видеоплеер
- `img/` — оптимизированные ассеты (WebP), в `img/products/` — постеры, изолированные фото приставки
- `fonts/` — локальные woff2 (Inter / Inter Tight / JetBrains Mono), без Google Fonts
- `policy.html` / `offer.html` / `consent.html` — юр. документы; `cert.html` есть в исходниках, но **скрыт с публичной страницы**
